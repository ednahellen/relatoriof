# GPSFA - Sistema de Controle de Estoque e Distribuição de Cestas Básicas

## Versão
1.0.0

## Funcionalidades

### 1. Estoque
- Importar produtos via Excel
- Registrar saídas
- Exportar relatórios (CSV, Excel, HTML)
- Visualizar estoque atual (entradas - saídas)
- Backup automático antes de importações

### 2. Cestas Básicas
- Usar modelos pré-definidos
- Adicionar itens manualmente
- Calcular necessidades (total, falta, sobra)
- Exportar planejamento e checklist para Excel
- Montar cestas (distribui mesmo com estoque insuficiente)

## Configuração do Servidor
- XAMPP com MySQL
- Porta 3306 liberada no firewall
- Usuário: root (senha vazia)
- Banco: dbfrancisco

## Configuração do Cliente
- Conexão remota via IP
- String no DataBaseConnection.cs

## Requisitos
- Windows 10/11
- .NET Framework 4.7.2
- XAMPP (servidor)
